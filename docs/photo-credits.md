# Photo credits — sample listings

The twelve sample listings created by `npm run seed:demo` use freely-licensed
photographs from Wikimedia Commons. They appear only on listings flagged
`is_demo`, which are labelled **Sample** in the UI and removed entirely by the
Demo / Real switch.

Most are CC BY-SA, which requires attribution and share-alike. That is what this
file is for. If you replace the sample listings with real student photos — which
you should, before any real pilot — none of this applies any more.
